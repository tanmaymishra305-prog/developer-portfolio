## Binary Number Representation

75 decimal to binary:
75 / 2 = 37 remainder 1
37 / 2 = 18 remainder 1
18 / 2 = 9 remainder 0
9 / 2 = 4 remainder 1
4 / 2 = 2 remainder 0
2 / 2 = 1 remainder 0
1 / 2 = 0 remainder 1
Binary = 1001011

110101 binary to decimal:
1*32 + 1*16 + 0*8 + 1*4 + 0*2 + 1*1 = 53

Computers use binary because digital circuits represent data using two states: 0 and 1.
